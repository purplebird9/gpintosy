## Debugging

#### QUESTIONS: BIOS 

>B1: What is the first instruction that gets executed?
答案： ljmp $0x3630, $0xf000e05b (即一条长跳转指令)。
解释： 这是 BIOS 的第一条指令，它告诉 CPU 跳转到 BIOS 的真正入口地址去执行初始化程序。


>B2: At which physical address is this instruction located?
答案： 0xffff0 
解释：
GDB 里看到的 [f000:fff0] 是 段地址:偏移地址
0xf000 左移 4 位 + 0xfff0 = 0xffff0，这就是物理地址。
这是 Reset Vector（复位向量），x86 CPU 电路设计规定，加电后 CPU 永远从这里开始读指令。



#### QUESTIONS: BOOTLOADER

>B3: How does the bootloader read disk sectors? In particular, what BIOS interrupt is used?
by the <read_sector> function.
int $0x13(0x7d1f).



>B4: How does the bootloader decides whether it successfully finds the Pintos kernel?
- whether it is a Pintos kernel. cmpb $0x20, %es:4(%si)
- whether it is a bootable kernel. cmpb $0x80, %es:(%si)


>B5: What happens when the bootloader could not find the Pintos kernel?
jump to label "no_boot_partition"
- puts("Not found.")
- Notify BIOS has failed. int $0x18


>B6: At what point and how exactly does the bootloader transfer control to the Pintos kernel?
- 时机：
    这个动作发生在 load_kernel 的末尾（反汇编 7cc4 - 7cd3）。此时，Bootloader 已经将磁盘中找到的内核代码完整加载到了内存地址 0x20000 开始的位置。
- 转移控制权的方式：
    代码从内存中提取出内核的 ELF 入口地址（Entry Point）。
    它将该地址存入内存位置 start，并设置好段寄存器。
    最终通过 ljmp *start 指令执行长跳转（Long Jump）。
